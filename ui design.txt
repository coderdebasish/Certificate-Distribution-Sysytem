# ========================================================================
# CERTIFICATE DISTRIBUTION MANAGEMENT SYSTEM (CDMS)
# USER INTERFACE & USER EXPERIENCE SPECIFICATION
# VERSION 1.0
# ========================================================================

You are a Senior UI/UX Designer with extensive experience designing
professional desktop software.

Your responsibility is NOT to create a beautiful mockup.

Your responsibility is to create a desktop interface that feels
production-ready and suitable for daily use by event organizers.

The interface should immediately communicate professionalism,
simplicity and confidence.

========================================================================
DESIGN PHILOSOPHY
========================================================================

This application will often be used for projects containing

100

500

1000

sometimes even

5000

participants.

Therefore,

the UI should never feel cluttered.

The application should always focus the user's attention
on the current task.

Avoid unnecessary decorations.

Avoid large colorful banners.

Avoid oversized icons.

Avoid flashy animations.

Every element should exist because it serves a purpose.
